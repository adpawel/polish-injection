## Useful resources for future bibliography

### Format:

N. \[title\]\(link\) - \<what it corresponds to\> 

### List

1. [AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents](https://arxiv.org/pdf/2406.13352) - setup and overview of Agent Dojo (root article)

2. [The Language Barrier:
Dissecting Safety Challenges of LLMs in Multilingual Contexts](https://aclanthology.org/2024.findings-acl.156.pdf) - Language gap

3. [An Empirical Evaluation of LLM Function Calling
in Enterprise Backend Systems: Latency, Reliability,
and Development Trade-offs](https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=11633280) - Performance of Qwen, Llama in agentic tasks

4. [Generative AI for autonomous data analytics](https://www.scopus.com/pages/publications/105027119221) - Performance of Qwen, Llama in agentic tasks

5. [Arabic Prompts with English Tools: A Benchmark](https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=11401864) - tool calling benchmark with language aspect

6. [FACILITATING MULTI-TURN FUNCTION CALLING FOR LLMS VIA COMPOSITIONAL INSTRUCTION TUNING](https://www.scopus.com/pages/publications/105010244456) - show need of specific architecture or framework to use large language models in agentic multi-step tasks 

7. For the performance of Bielik and PLLuM there is a gap in clear benchmarks on agentic tasks and tool calling
